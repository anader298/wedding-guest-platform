Check for mistakes

Looks for things that are easy to miss: the same family twice, more guests than seats, invites sent long ago and never opened, late answers, wrong-looking phone numbers, weddings coming up with no helper active, designs never published.

Backups

The website makes a copy of every wedding every night at 03:00 (UTC). Nightly copies are kept 90 days, the first of each month and every copy you make by hand are kept for ever, and a copy is taken when a wedding is archived. If the GitHub copy is set up (docs/BACKUPS.md), every backup is also written there. Pictures are kept separately and are not inside backups.
